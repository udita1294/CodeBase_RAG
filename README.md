# Codebase RAG — AI Software Engineer

Codebase RAG is an AI-powered system that allows developers to
ask questions about an entire GitHub repository.

## Planned Features

- GitHub repository ingestion
- Code-aware parsing
- Intelligent code chunking
- Vector search
- Dependency graph
- Hybrid RAG
- Reranking
- Git history analysis
- Code citations
- RAG evaluation

## Architecture

GitHub Repository
        ↓
Repository Ingestion
        ↓
Code Parsing
        ↓
Code Chunking
        ↓
Vector Database + Dependency Graph
        ↓
Hybrid Retrieval
        ↓
LLM
        ↓
Answer + Code Citations
